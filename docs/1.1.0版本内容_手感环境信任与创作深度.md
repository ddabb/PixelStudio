# 像素画工作室 · v1.1.0 版本内容：手感·环境信任·创作深度

> 承接《像素画工作室开发计划_买断制像素画与逐帧动画编辑器.md》（v1.0.0 交付）与《1.0.1优化计划_撤销稳定性与导出链路.md》（P7/P9 部分吸收，见其 §2.1）。
> 版本基调：v1.0.0 交付了功能全集；v1.1.0 不加新模块，聚焦四层体验——**手感**（触感/光标/动效）、**环境信任**（深色模式、工程备份）、**创作深度**（文本/对称/抖动）、**交付扩展**（精灵图集）。
> 版本号：versionName 1.1.0 / versionCode 1001000 / buildVersion 19。核心原则不变：**离线、买断、零网络权限。**

## 1. 特性清单（四层）

### 1.1 手感层（1.1.0-A）

- **触感反馈 Haptics**：落笔 tick 12ms / 确认 confirm 25ms（usage 'touch'），异常全静默降级；module.json5 增 `ohos.permission.VIBRATE`（normal 级免弹窗——「零网络权限」承诺不变）。
- **悬停像素光标 BrushCursorOverlay**：鼠标/2in1 悬停显示笔宽块（按 Raster.stamp 偏移 `-floor((size-1)/2)` 精确对齐）+ 镜像 ghost + 填充/吸管单格档；HoverEvent.x/y 可缺省回退 -1。
- **微动画**：调色板面板出入场 220ms easeOut（UIContext.animateTo + OPACITY/translate）、帧缩略选中描边 150ms。
- **洋葱皮吸色污染修复**：blend 前留 pickBuf 副本、readComposed 读副本——取色不再读到 30% 幽灵色。

### 1.2 环境信任层（1.1.0-B 深色 / 1.1.0-C 备份）

- **深色模式端到端验证**（零代码改动，dark token 此前已齐）：17 token 双主题齐备；设备实测采样 page_background=#1A1A1A、card_background=#242424、canvas_backdrop=#2E2E3A 与 dark token 逐字节一致，切回浅色 #F5F5F5/#FFFFFF 与 base 一致；运行中实时切换生效。
- **工程备份/恢复 .pxba**：
  - 容器 `core/BackupCodec.ets`：['PXBA'][ver u16][count u32][rawLen u64][zlib 条目流]；条目名白名单防路径穿越；魔数/版本/长度/截断/重名全查坏档返回 undefined 永不崩。
  - 读写经 ProjectStore/PaletteStore（恢复=不存在才写，非破坏；调色板字节透传保真）。
  - `components/BackupDialog.ets`：DocumentViewPicker save/select 免权限 + 双语 + 用户取消静默；列表页脚「备份工程」入口。

### 1.3 创作深度层（1.1.0-D）

- **文本工具**：内置 Font5x7 5×7 点阵字库（大写字母/数字/常用标点；无字形字符跳过）+ 字号 1×/2×/3× + 活字宽实时显示 + 越界红提示「越界部分将被裁剪」+ 输入自动大写化；TextToolDialog scrim 对话框，Back 键先收框不退编辑器；插入经 DocOps.insertText 入撤销栈（可撤销），随自动保存/退出保存落盘。
- **四向对称**：对称按钮 关/X/Y/XY 四态（Raster.stamp 镜像落笔 + 光标 ghost 同步）。
- **抖动填充**：FloodFill visited-BFS 抖动棋盘（可证终止，无重复访问）。
- **修复**：对话框 scrim 改 Stack 兄弟层根治根节点 onClick 冒泡误关；Back 误退编辑器修复。

### 1.4 交付扩展层（1.1.0-D）

- **导出格式 2×2**：PNG / GIF / 拼豆图纸 / **精灵图集**。
- **精灵图集 SheetRender**：1× 横排条带布局 + 坐标 JSON（帧名/xywh/总尺寸）分享，可被 Cocos/Unity/Godot 直接切片；PNG 1/2/4/8× 最近邻多倍率沿用 v1.0.0。
