# 像素画工作室 · 1.0.1 优化计划：撤销稳定性与导出链路

> 承接《像素画工作室开发计划_买断制像素画与逐帧动画编辑器.md》（v1.0.0 立项）。
> 版本基调：v1.0.0 已交付画布/工具/图层/选区/调色板/帧/撤销重做/导出/拼豆/工程管理等 P0 全集。1.0.1 的核心是「把创作不丢笔、不丢工程、导出不翻车」做扎实——撤销混合栈与自动保存是付费创作工具的生命线，导出链（GIF/精灵图/拼豆）是交付价值所在。

## 1. 背景与定位

v1.0.0 撤销栈声明 ≥100 步混合栈、自动保存 30s 间隔 + 退出触发，但跨图层/选区/帧的混合操作一致性、杀进程恢复的数据损失边界尚未系统验证；拼豆与 GIF 量化在极端调色板下可能偏色；P1 的 256 画布 / 混合模式 / 精灵图 / 文本工具 / 导入图层是高频呼声。1.0.1 以稳定性为底座，前移核心 P1。

核心原则：**离线、买断、不联网不变；撤销与自动保存必须零信任失败；导出像素级最近邻不模糊。**

## 2. 优化项清单

| 编号 | 模块 | 现状（v1.0.0） | 1.0.1 优化 | 验收 |
|---|---|---|---|---|
| P1 | 撤销重做栈 | ≥100 步混合栈 | 跨图层增删/重排、选区移动/复制、帧增删/排序、调色板编辑全纳入同一混合栈；置灰态正确；100 步边界压测 | 连续 200 步混合操作可完整撤销/重做，状态一致不串 |
| P2 | 自动保存恢复 | 30s 间隔 + 退出触发 | 杀进程（强杀）恢复实测，数据损失 ≤30s；恢复后撤销栈可接续；工程列表缩略图实时刷新 | 强杀 3 次均能在 ≤30s 损失内恢复，缩略图正确 |
| P3 | 选区增强 | 静态虚线蚂蚁线 | 蚂蚁线流动动画前移；选区移动/复制/删除跨层边界处理；选区与当前层不一致时提示 | 选区全操作无残留、无越界 |
| P4 | 洋葱皮 | 上一帧 30% 叠加 | 多帧参考（上 N 帧可选）、透明度可调、开关独立 | 多帧参考叠加正确，性能不降 |
| P5 | GIF 量化 | 256 色中位切分 / 按调色板映射 | 透明处理（alpha=0 帧间一致）；帧延迟边界；调色板映射模式偏色回归 | 导出 GIF 在主流查看器色彩正确、透明不乱 |
| P6 | 拼豆图纸 | 豆色量化 + 材料清单 + 分板图 | 真实豆色 RGB 渲染预览；材料清单数量/占比精度；29×29 分板切块边界 | 拼豆图纸与实物豆色一致，清单可照单购买 |
| P7 | 导出前移 | P1 计划 | 精灵图导出（横排条带 + 自定义 padding）前移；PNG 多倍率（1/2/4/8×）最近邻；拼豆图纸导出 | 精灵图可被 Cocos/Unity/Godot 直接切片 |
| P8 | 画布与层前移 | P1 计划 | 256×256 画布 + 16 层（按帧懒加载控内存）；图层混合模式（正常/正片叠底/滤色/叠加） | 大画布多帧内存可控，混合模式实时正确 |
| P9 | 工具前移 | P1 计划 | 选区旋转 90° 与水平/垂直翻转；文本工具（系统字体光栅化贴网格）；PNG 导入为图层（最近邻缩放） | 上述工具在 32/64 画布实测无锯齿、对齐网格 |

## 3. 风险与对策

| 风险 | 对策 |
|---|---|
| 大画布 + 多帧内存 | 帧懒加载 + 离屏缓冲复用，监控峰值，超阈值降质提示 |
| 撤销栈与自动保存并发 | 保存点打断撤销栈边界清晰，恢复后栈可续 |
| GIF/拼豆偏色 | 量化前拍平图层、统一 alpha 处理，建立色卡回归 |

## 4. 非目标（明确不做）

- 不做云同步 / 社区 / 账号体系
- 不做订阅 / 广告 / 内购解锁
- 不做 AI 生成 / 内容运营
- 不做矢量/3D（保持像素工具定位）

## 5. 验收总览

- 稳定性：撤销栈 200 步混合 + 强杀恢复 ≤30s 双达标
- 导出：GIF 不偏色、精灵图可用、拼豆清单精确
- 能力前移：256 画布/16 层、混合模式、选区变换、文本、PNG 导入图层
- 全链路离线、买断说明与版本号正确
