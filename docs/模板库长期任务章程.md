# 模板库长期任务章程

> 立章：2026-11-05（v1.3.0 批）。本文件是「分类模板库」长期任务的固化章程，
> 后续每批模板扩充均以本章程为准，批后在本文件追加批次日志。

## 1. 背景与目标

PixelStudio 的价值主张是「买断制像素画与动画编辑器」。模板库降低冷启动门槛
（新用户打开即有可临摹/魔改的成品），同时为老用户提供持续的内容更新预期
（每版本新增一批模板 = 可感知的版本价值）。

- 形态：工程列表页顶栏「模板库」入口 → 全屏画廊（分类页签 + 卡片网格 +
  预览确认）→「使用模板」= 以模板为底新建独立工程（沙箱新 id，不改模板源）。
- 长期性：模板库随版本滚动扩容，不设总量上限；每批 8~15 个，版本号 minor +1
  时至少交付一批。

## 2. 不侵权三原则（红线，逐批自查）

1. **全原创程序化绘制**：所有模板由 `scripts/make_templates.py` 中的绘制函数
   逐像素生成，禁止临摹/描摹任何第三方作品的像素排布；禁止导入外部图片。
2. **泛型题材命名**：只做题材类型（柴犬幼犬、宝箱、爱心……），不做任何商标、
   角色 IP、影视/游戏具名实体；命名避开商标词（中英双语均适用）。
3. **公开调色板**：仅使用 PICO-8 与 GB-DMG 两套公开调色板（仓库既有常量），
   不引入第三方作品的专属配色。

## 3. 分类体系（页签 = 全部 + 六类）

| 分类键 | 中文 | 内容方向 |
| --- | --- | --- |
| animals | 动物 | 现实向动物、宠物 |
| scenery | 风景 | 场景、自然景观（多层示范） |
| food | 食物 | 食物、静物 |
| creatures | 奇幻生物 | 人形角色、幻想生物 |
| items | 物品 | 道具、容器、物件 |
| glyphs | 图形 | 图标、符号、装饰纹样 |

规则：每类每批至少 1 个新增；单模板只属一类；`TPL_CATEGORIES` 顺序即页签顺序，
不得随意重排（历史卡片位置稳定）。

## 4. 产物与生成管线

```
scripts/make_templates.py        # 唯一事实源：绘制函数 + DEMOS 登记 + 发射器
  ├→ entry/src/main/resources/rawfile/templates/{id}.pxs / {id}.thumb
  ├→ entry/src/main/ets/viewmodel/TemplateDefs.ets   # GENERATED，勿手改
  └→ scripts/templates_manifest.json                 # 仅 verify 脚本消费

scripts/verify_templates.py      # 一致性校验 + PIL 预览（.cache/tpl_preview/）
```

- `TemplateDefs.ets` 头部标注 GENERATED：改模板必须改 `make_templates.py`
  再重新生成，禁止直接编辑生成物（防漂移，verify 以 manifest↔ets id 序列
  逐条比对）。
- 模板规格约束：16~48px 边长、1~2 帧（示例工程入库条目可例外）、
  fps 4~8、PICO-8/GB-DMG 调色板。
- 清单不走 JSON.parse（仓库零先例、ArkTS 类型断言风险）：Python 生成
  typed 常量，manifest 仅供 Python 侧校验。
- 生成物确定性输出：重跑字节一致（无时间戳/随机量进文件）。

## 5. 批次五步流程（每批必做）

1. **绘制**：在 `make_templates.py` 增绘制函数（先过三原则自查）+ 登记
   `TPLS`/`DEMO_TPLS`；规格参数（名称/描述/分类/尺寸/帧/fps）随函数内联。
2. **生成与目检**：`py -3 scripts/make_templates.py` 生成产物；
   `py -3 scripts/verify_templates.py` 校验一致并输出 `.cache/tpl_preview/`
   预览；逐张目检画风（主体可辨认、无杂点、构图完整），不合格回到第 1 步。
3. **应用侧**：`TemplateDefs.ets` 自动再生即可（UI 读 `TEMPLATE_DEFS` 动态渲染，
   新模板零 UI 改动）；新增分类才需要 `tpl_cat_<cat>` 字符串键。
4. **测试**：`templateDefsValid` 用例更新总数断言（15 → N）；
   `instantiateTemplateRoundTrip` 无需改动（读 `TEMPLATE_DEFS[0]`）。
5. **收尾**：本章程批次日志表补一行；版本升位；主计划 §15 补行。
